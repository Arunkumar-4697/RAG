# 02.md - Frontend Component Architecture

Act as a senior React architect.

I already have a working UI prototype. -- frontend/documind_application.tsx

Refactor it into a maintainable React JavaScript application.

Do not use TypeScript.

Do not use Bootstrap.

Use:

* React JS
* Redux Toolkit
* Material UI
* Axios

Keep CSS in separate .css files.

Use CSS modules or individual CSS files instead of putting styles inside components.

---

# Goal

Transform the prototype into reusable components.

Focus on structure and maintainability.

# Important

Preserve the appearance and functionality of the existing prototype.

Refactor into reusable components.

Avoid overengineering.

Do not introduce contexts or custom hooks yet.

Do not optimize prematurely.

We will introduce:

* custom hooks
* provider abstractions
* streaming responses
* memoization

in future phases.
