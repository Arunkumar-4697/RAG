# Storage Structure

Assume a single user.

Root:

```text
storage/

    primary_user/
```

Folders created by the user will exist under:

```text
storage/

    primary_user/

        aws/

        docker/

        kubernetes/
```

Files are stored inside folders.

Example:

```text
storage/

    primary_user/

        aws/

            aws.pdf

            s3.pdf

        docker/

            containers.pdf
```

No database is required.

Filesystem is the source of truth.

# Folder APIs

Implement:

---

## Create Folder

```http
POST /folders
```

Request:

```json
{
    "folder_path": "aws/subfolder"
}
```

Create:

```text
storage/primary_user/aws/subfolder
```

---

## List Folders

```http
GET /folders
```

Response:

Returns a recursive tree of folders and files.

```json
[
  {
    "name": "aws",
    "type": "folder",
    "path": "aws",
    "children": [
      {
        "name": "aws.pdf",
        "type": "file",
        "path": "aws/aws.pdf"
      }
    ]
  }
]
```

---

## Delete Folder

```http
DELETE /folders/{folder_path}
```

Delete folder recursively along with all files and subfolders inside.

---

# File APIs

---

## Upload File

```http
POST /files/upload
```

Multipart upload.

Parameters:

* folder_path (supports nested paths like "aws/ec2")
* file

Supported:

* pdf
* txt
* md

Save inside:

```text
storage/primary_user/{folder_path}
```

---

## Delete File

```http
DELETE /files
```

Request:

```json
{
    "file_path": "aws/aws.pdf"
}
```

Delete only the specified file.
