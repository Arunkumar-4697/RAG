# Hybrid Chunking Strategy

Use semantic chunking.

Generate sentence embeddings.

Compare adjacent sentence embeddings using cosine similarity.

Semantically similar sentences belong to the same chunk.

Topic changes immediately start a new chunk.

---

# Chunk Size

Maximum:

```text
800 characters
```

---

# Overlap

Overlap:

```text
150 characters
```

Overlap should only occur when splitting because the chunk exceeded 800 characters.

Never overlap across semantic boundaries.

Example:

Current chunk:

450 characters

Next sentence is semantically different

↓

Create a new chunk.

No overlap.

# Qdrant Record Pattern

Each point should contain:

```python
{
    "id": "...",

    "vector": [...],

    "payload": {
        "model_used_for_chunking":
            "BAAI/bge-small-en-v1.5",

        "relative_path":
            "primary_user/aws/aws.pdf",

        "folder_name":
            "aws",

        "file_name":
            "aws.pdf",

        "page_number":
            12,

        "chunk_index":
            15,

        "text":
            "..."
    }
}
```

Do not duplicate embeddings inside payload.

Store embeddings only in the vector field.

# Delete File Behaviour

When deleting a file:

Delete:

* file from storage

and

* all associated vectors from Qdrant

Use metadata filters:

```python
file_name
relative_path
```

to remove corresponding chunks.

---

# Delete Multiple Files

Support deleting multiple files.

All associated vectors must also be deleted.

---
